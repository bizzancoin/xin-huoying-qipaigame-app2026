```text
HY/
├── client/       # 客户端与引擎相关工程
├── Server/       # 平台服务、公共组件与子游戏
├── WebCode/      # Web 前台与管理后台
├── DB/           # 数据库相关文件

├── UI_Game/      # 游戏界面工程与资源

```
